# Дизайн-ревью: Уральские гренки

## Текущее состояние

Тёплый артизанальный скевоморфный стиль. Хорошая основа: согласованная палитра (коричневые/кремовые тона, акцент `#b46a46`), иерархия секций, SVG-иконки, адаптивность. Но есть места, где дизрайфт накапливается.

## Найденные проблемы

### P0 — Качество дизайна

1. **`section + section { border-top }`** — тонкая линейка между КАЖДОЙ секцией. Создаёт визуальный шум, особенно на переходах между `section-alt` и обычной секцией — рамка режет фоновый цвет. Скевоморфизм должен опираться на тени и градиенты, не на разделители.

2. **`.cta-strip { border-top }`** — то же самое, дублирует рамку на CTA-секции.

3. **Dead contact form** — `action="#"` без JS. Нужен хотя бы `mailto:` fallback или явное указание «Позвоните нам».

### P1 — Inline-стили → CSS-классы

Около 25 inline-`style` атрибутов размазаны по 5 шаблонам:

| Файл | Проблема |
|---|---|
| `post.html` | `padding-bottom:0`, `padding-top:0` (×3), пост-футер грид |
| `page.html` | `padding-top:0`, фигура, контактная форма (btn `width:100%`) |
| `product.html` | `padding-bottom:0`, кнопка `width:100%`, note внизу |
| `categories/single.html` | Стили на img (обводка, тень, `max-height`, радиус) |
| `categories/list.html` | `display:grid` напрямую в атрибуте |
| `404.html` | `style` на параграфе |

### P2 — Мелкие улучшения

- **`active` навигация** — текущая страница не подсвечивается в меню
- **`.product-card-image`** — мёртвый CSS (дублирует `.product-card-img`, не используется)
- **Контента мало** — 2 продукта, 2 рецепта, 1 новость (не исправляется шаблонами, но стоит отметить)

## Предлагаемые изменения

### 1. Убрать границы секций (CSS)
- Удалить `section + section { border-top }`
- Удалить `cta-strip { border-top }`
- Секции разделяются отступами и чередованием фона — этого достаточно

### 2. Классы для inline-стилей (CSS + templates)
Добавить классы:
- `.section-pt-0` — `padding-top: 0`
- `.section-pb-0` — `padding-bottom: 0`
- `.post-nav-grid` — грид для prev/next в посте
- `.post-figure` — фигура с изображением
- `.btn-full` — кнопка `width:100%; justify-content:center`
- `.categories-grid` — грид для списка категорий
- `.categories-card` — карточка категории
- `.photo-figure` / `.photo-img` — стилизованное изображение в шаблоне

### 3. Форма контактов (page.html)
- Убрать `action="#"`  
- Заменить на кнопку-ссылку `mailto:`

### 4. Навигация (base.html)
- Добавить проверку `current_url` для `class="active"`

### 5. Мёртвый CSS
- Удалить блок `.product-card-image`

## Порядок выполнения

1. CSS: новые классы + удалить границы секций + мёртвый CSS
2. `base.html`: active nav
3. `post.html`: inline styles → CSS
4. `page.html`: inline styles → CSS + form fix
5. `product.html`: inline styles → CSS
6. `categories/single.html`, `list.html`: inline styles → CSS
7. `404.html`: inline style → CSS
8. Собрать (`just zola build`)

## Что НЕ делаем (осознанно)
- Не трогаем контент (продукты/рецепты) — это задача наполнения
- Не меняем палитру — она согласованная
- Не рефакторим структуру HTML — только стилизацию
- Не добавляем JS-функционал формы — это отдельная задача
